# Portfólio Executivo — Patrícia de Oliveira

Site estático, responsivo e sem dependência de serviços pagos. Preparado para publicação gratuita no GitHub Pages.

## Arquivos
- `index.html`: conteúdo e estrutura do site.
- `styles.css`: identidade visual premium e responsividade.
- `script.js`: menu mobile e ano automático no rodapé.
- `assets/`: currículo executivo PDF e favicon.

## Publicar gratuitamente no GitHub Pages

1. Crie uma conta gratuita em https://github.com/ (se ainda não tiver).
2. Clique em **New repository**.
3. Nome sugerido: `portfolio-patricia`.
4. Marque **Public** e crie o repositório.
5. Dentro do repositório, escolha **Add file → Upload files**.
6. Envie todos os arquivos e pastas desta pasta, incluindo `index.html`, `styles.css`, `script.js` e `assets/`. Atenção: `index.html` precisa ficar na raiz do repositório, não dentro de uma segunda pasta.
7. Clique em **Commit changes**.
8. Abra **Settings → Pages**.
9. Em **Build and deployment**, escolha **Deploy from a branch**.
10. Em **Branch**, selecione `main` e pasta `/(root)`, depois **Save**.
11. Aguarde a publicação. O endereço ficará parecido com:
   `https://SEU-USUARIO.github.io/portfolio-patricia/`

Se preferir um endereço no formato `https://SEU-USUARIO.github.io/` sem o sufixo do projeto, o repositório deve ter exatamente o nome `SEU-USUARIO.github.io`.

## Como atualizar
Edite os arquivos localmente ou use o botão de edição do GitHub. Depois faça commit das alterações; o Pages publica a nova versão automaticamente.

## Antes de divulgar
- Confira se telefone, e-mail e LinkedIn estão corretos.
- Confira o PDF do currículo e teste o download.
- Revise todos os cases e indicadores.
- Se quiser incluir fotografia, substitua a área gráfica do hero por uma foto profissional autorizada.
- Recomendações: só incluir depoimentos reais, com autorização de quem escreveu.
- Não há formulário de contato com backend: os botões usam e-mail, WhatsApp e LinkedIn diretamente, evitando custos e integrações.

## Gratuidade
O GitHub Pages oferece hospedagem gratuita para repositórios públicos em contas GitHub Free, sujeita aos limites e termos do GitHub Pages. Não é necessário comprar domínio: o endereço `github.io` é gratuito.
